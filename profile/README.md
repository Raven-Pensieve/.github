## ✨ 关于我们 | About Us

**Raven-Pensieve** —— 一个专注于 **Obsidian** 插件与工具开发的开源组织。

我们的名字源自哈利波特中的「冥想盆」(Pensieve)，象征着知识的存储与回溯。我们致力于通过精心设计的插件，让 Obsidian 成为更强大的第二大脑。
